# Escopo do Projeto — BetAnalytics IA

## 1. Nome do projeto

BetAnalytics IA

## 2. Descrição

O BetAnalytics IA é uma plataforma multiesportiva de análise estatística baseada em dados históricos, probabilidades e tendências esportivas.

O sistema tem como objetivo calcular a probabilidade de acontecimentos em eventos esportivos e apresentar sugestões estatísticas com justificativas baseadas em dados.

## 3. Objetivo principal

Criar um sistema em Python capaz de:

- coletar dados esportivos;
- analisar estatísticas históricas;
- calcular probabilidades;
- apresentar porcentagens de possíveis acontecimentos;
- sugerir possibilidades estatísticas;
- explicar o motivo da sugestão;
- exibir os dados em uma interface simples para o usuário.

- Selecionar esporte

## 6. Exemplo de saída do sistema

```text
Evento: Lakers x Celtics

Probabilidades:
- Lakers vencer: 57%
- Celtics vencer: 43%
- Over 215 pontos: 68%
- Under 215 pontos: 32%

Sugestão estatística:
Over 215 pontos

Justificativa:
Esse cenário ocorreu em 9 dos últimos 10 jogos analisados.

Aviso:
Análise baseada em dados históricos e probabilidades, sem garantia de resultado.
